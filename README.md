# Lean 4 Math Formalization Projects

This repository contains independent projects focused on mathematical formalization using **Lean 4** and **MathLib4**. 

## Contents
1. **SetTheory.lean**: Formal verifications of foundational set theory properties, including subset transitivity and commutativity of intersections. Demonstrates manual proof construction using fundamental Lean tactics (`intro`, `exact`, `apply`, `constructor`).
2. **NumberTheory.lean**: Features a custom recursive definition for arithmetic progressions and a formal proof by mathematical induction using structural cases and the `ring` tactic.

## Technical Stack
* **Language:** Lean 4
* **Library:** MathLib4
* **Core Tactics Utilized:** `induction`, `calc`, `rw`, `simp`, `ring`, `ext`
